# YelpCamp

A full-stack web application that allows outdoor enthusiasts to discover, create, and manage campgrounds worldwide. Key features include:

 - Interactive Google Maps integration for visualizing and selecting campgrounds
 - CRUD functionality: Create, Read, Update, and Delete campground listings
 - User authentication system for secure login and signup
 - MongoDB backend for efficient data management and storage
 - Responsive design for seamless use across devices

Perfect for campers and adventurers looking to explore new destinations or share their favorite spots with the community.
